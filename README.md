# TaxiDriver AI Website

Official website for TaxiDriver AI - an intelligent co-pilot for professional drivers.

## About

TaxiDriver AI combines airport arrivals, rail and coach feeds, live traffic, weather and local events to forecast pickup hotspots and guide drivers to the next best fare.

### Key Features

- **Hotspot Forecasting**: Predictive demand maps around airports, stations, and venues
- **Multi-modal Arrivals**: Flights, trains, and coaches unified and ranked by revenue potential
- **Driver Analytics**: Session earnings, success rate, time-to-fare and ROI trends
- **Real-time Data**: Live arrivals, weather impact, and event proximity scoring
